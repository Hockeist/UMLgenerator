# UMLgenerator — Кроссплатформенный генератор диаграмм классов UML

Настольное приложение на **C++17** и **Qt 6** для автоматического анализа исходного кода и построения интерактивных UML-диаграмм классов.

## Основные возможности

* **Мультиязычный анализатор кода:** C++ (`libclang`), Python и C#.
* **Определение всех 5 видов связей UML:** Наследование, Композиция, Агрегация, Ассоциация, Зависимость.
* **Определение кратности связей:** `1`, `0..1`, `0..*`.
* **Интерактивная визуализация:** ортогональная маршрутизация линий, перетаскивание карточек, масштабирование.
* **Экспорт:** сохранение диаграмм в **PNG** и **SVG**.

## Скачивание готовых сборок (Windows, Linux, macOS)

1. Перейдите на вкладку **Actions** вверху страницы репозитория.
2. Откройте верхнюю успешную сборку **Build App (Windows, Linux, macOS)**.
3. Внизу в разделе **Artifacts** скачайте архив для вашей системы:
   * `UMLgenerator-Windows-Portable` (Windows)
   * `UMLgenerator-Linux-x64` (Linux)
   * `UMLgenerator-macOS-Installer` (macOS)
